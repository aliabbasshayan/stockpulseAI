# ⚡ StockPulse AI - Stock Price Prediction & Analytics

StockPulse AI is a web application built with Streamlit and Machine Learning (Ridge Regression) that provides real-time stock price analytics, technical indicator evaluations, and short-term future price forecasting using Financial ML pipeline concepts.

---

## 🚀 Features

- **Live Market Data:** Fetches automated, real-time stock price data via `yfinance`.
- **Interactive Visualizations:** Interactive Candlestick and Line charts built with `Plotly`.
- **Technical Indicators:** Calculates RSI (14), MACD (12, 26, 9), Moving Averages (SMA 5, 20, 50), and Bollinger Bands automatically.
- **ML Price Forecasting:** Predicts recursive daily stock close prices using Scikit-Learn's `Ridge Regression`.
- **Backtesting & Feature Importance:** Displays model accuracy metrics ($R^2$, MAE, RMSE, Directional Hit Rate) and visualizes feature weights.
- **Stock Comparison & Correlation:** Enables side-by-side comparison of multi-stock price performance and return correlation heatmaps.

---

## 🛠️ Tech Stack

- **Frontend / Framework:** [Streamlit](https://streamlit.io/)
- **Data Source:** [yfinance](https://pypi.org/project/yfinance/)
- **Machine Learning:** [Scikit-Learn](https://scikit-learn.org/) (Ridge Regression, StandardScaler)
- **Data Manipulation:** [Pandas](https://pandas.pydata.org/), [NumPy](https://numpy.org/)
- **Visualization:** [Plotly](https://plotly.com/python/)
